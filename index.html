Four rewrites of the same idea: can a model learn my typing well enough to notice when something's off? V1 was a linear regression forecasting my WPM milestones. Deepfake Detection

Spatial-Frequency Attention Network · Computer Vision

A three-branch hybrid: pretrained MobileNetV2 spatial branch, a channel-wise attention gate, and an FFT frequency-domain branch fused into a 1,344-dim vector. Trained on FaceForensics++ C23 (128,477 train / 27,493 val / 26,276 test images) with Adam, ReduceLROnPlateau, and label smoothing. The frequency branch is what pushed it past baseline — GAN upsampling leaves periodic spectral artifacts a spatial-only model tends to miss. Honest caveat: cross-dataset generalization to DFDC or Celeb-DF is still untested, and Real-class precision (0.74) has room to improve with focal loss.

Smart Face Recognition Access System

Embedded Systems + Computer Vision · Bahçeşehir University course project, team of 4
→ github.com/youssefzuaiter/Smart-Face-Recognition-Access-System

A 3-layer event-driven access system, not just a locked door: a sensing layer (HC-SR04 ultrasonic, LDR, vibration sensor, RC522 NFC) feeds an Arduino UNO, which hands off over serial to a Python/OpenCV program running LBPH face recognition on a laptop webcam. Known faces get the servo-driven door and a relay-actuated "lock"; unknown ones get denied, logged, and photographed. NFC card/keychain and an IR remote back up the camera for entry and admin control. Built with three teammates (Majd Javadah, Yousef Salama, Walid Kobahalabi) for CMP3010 — my part spanned the Python recognition pipeline and the hardware/software integration over serial.

The real engineering was in the conflicts: the IR remote library and Arduino's tone() both claimed Timer 2, so the buzzer was corrupting remote signals — fixed by toggling the buzzer pin manually instead. The NFC reader's constant SPI polling was doing the same to the IR receiver — fixed by polling every 600ms and pausing the IR receiver around each card read. LBPH struggled with glasses and beards until we pushed training data to 150 images per person and retuned the confidence threshold. And the servo/relay drew enough current to brown out the Arduino on USB power, solved with a 9V battery through the barrel jack for a stable regulated supply.

Cloud-Native Bookstore API

Kubernetes & DevOps

A containerized Flask + MongoDB CRUD API, deployed to a Kubernetes cluster rather than left as a local script. MongoDB runs as a StatefulSet with a persistent volume claim (headless service, so pods get stable DNS) — the Flask side is a 2-replica Deployment behind a NodePort Service, reading its Mongo connection details from a ConfigMap instead of hardcoding them. The API exposes a /health endpoint that actually pings the database, which is what the liveness and readiness probes hit — the kind of detail that matters in a real cluster and doesn't come up in a tutorial.
